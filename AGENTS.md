# Repository Instructions

## Scope

- Keep changes specific to BrainCo Revo3.
- Keep examples compatible with the SDK version declared by the repository.
- Preserve equivalent behavior across corresponding C++ and Python examples.

## Safety And Validation

- Use safe, non-moving defaults unless movement is explicitly requested.
- State required platform, hardware, transport, and firmware prerequisites.
- Do not present mock-mode or non-moving checks as validation of real hardware behavior.
- Treat unverified device or firmware behavior as unverified, not supported.

## Public Repository

- Do not add credentials, private endpoints, internal codenames, or local filesystem paths.
- Keep public documentation self-contained and state unsupported or unverified behavior explicitly.

## Code Style

- Write code, identifiers, comments, and commit messages in English.
