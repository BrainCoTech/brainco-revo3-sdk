# Writing Profile

- Applies to: Public README files, C/C++ and Python example guides, Revo3 API and device references, GUI instructions, integration notes, and example reviews.
- Selected items: `core`, `sdk-docs`, `portable-md`, `no-latex`, `public-docs`.
- Conditional items:
  - Use `zh-cn` for Chinese documentation.
  - Use `en-sdk` for English SDK, API, or example documentation.
  - Use `cross-role` for protocol, transport, motion, collision, hardware, or validation documents shared across SDK, firmware, robotics, application, test, support, or delivery roles.
- Local overrides: Preserve Revo3-only scope, release-matched SDK versions, safe default examples, platform and hardware prerequisites, API/source-of-truth boundaries, and consistency between C/C++ and Python examples. Do not imply that mock or non-moving examples validate real hardware behavior.
