# Revo3 内部触觉压力测试

本目录只包含内部交付所需的 `hp_*` 触觉读取压力测试，不作为客户应用模板，也不替代完整源码仓库中的发布回归与 HIL 流程。

| 脚本 | 设备效果 | 默认时长 | 用途 |
| --- | --- | ---: | --- |

两个脚本均不发送运动、标定、配置改写、重启或固件升级命令。运行前仍需核对设备身份、协议、端口和从站 ID；发现结果或健康状态异常时不得继续扩大测试时长。

从归档根目录运行：

```bash
python \
  --port <PORT> --slave-id 126 --duration 30

python \
  --port <PORT> --slave-id 126 --duration 600
```

先用 `--help` 确认当前脚本参数。测试记录至少包含 SDK 版本、设备 SN、全部固件版本、硬件版本、协议、端口、适配器、操作系统、完整命令行、持续时间、循环数、错误数和最终退出状态。未执行或中途终止不得记为通过。
