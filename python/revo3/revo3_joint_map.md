## 3. SDK 逻辑关节与映射规则

### 3.1 四指控制映射规则 (`move_finger`)
在 SDK 2.x 接口中，四指的 `finger_index` 取值范围为 `1..=4`（从食指到小指）：

- `finger_index = 1`：**食指 (Index)** ➔ 起始关节 J12（范围 J12 ~ J15）
- `finger_index = 2`：**中指 (Middle)** ➔ 起始关节 J8（范围 J8 ~ J11）
- `finger_index = 3`：**无名指 (Ring)** ➔ 起始关节 J4（范围 J4 ~ J7）
- `finger_index = 4`：**小拇指 (Pinky)** ➔ 起始关节 J0（范围 J0 ~ J3）

计算公式：`start_joint_id = (4 - finger_index) * 4`。传入非法索引（如 0 或 >4）将由 SDK 校验并阻断报错。

每根四指传入的 4 个目标位置固定遵循：`[Abd, MCP, PIP, DIP]`。

### 3.2 大拇指关节编号

拇指的 5 个逻辑关节按 `[J16, J17, J18, J19, J20]` 排列。
`move_thumb()` 接受按上述编号顺序排列的 5 个目标角度。

调用 SDK 时使用逻辑关节编号或 API 规定的数组顺序，由 SDK 处理底层协议映射。

## 4. 通信拓扑与默认设备 ID

- **默认从机 ID (Slave ID)**：
  - 默认左手 ID：`126`
  - 默认右手 ID：`127`
  - 广播控制 ID：`0`（向 ID 0 发送命令将同步控制总线上所有设备）
- **开机自校准安全须知**：
  - 启用上电自动校准时，灵巧手上电后会执行零位校准，手指可能运动；
  - **安全警告**：若上电时灵巧手正抓握物体，自校准会导致物体脱落，请务必在空载状态下上电启动。
