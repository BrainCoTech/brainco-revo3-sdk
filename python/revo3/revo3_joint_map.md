## 2. 21 主动自由度与物理运动角度范围

Revo3 智能灵巧手共配置 **21 个全主动独立驱动自由度**，全关节支持反驱与关节级控制，各手指关节严格遵循人手生物力学结构：

| 主动关节 | 逻辑关节序号 | 自由度名称 | 物理可达运动角度范围 | 运动学与解剖说明 |

| | J1 | **MCP** 掌指关节屈伸 | `0° ~ 85°` | 掌指关节屈伸 |
| | J2 | **PIP** 近端指间关节屈伸 | `0° ~ 85°` | 近端指间关节屈伸 |
| | J3 | **DIP** 远端指间关节屈伸 | `0° ~ 85°` | 远端指间关节屈伸 |

| | J20 | **CMC Flex** 腕掌关节屈伸 | `0° ~ 60°` | 拇指垂直于手掌平面弯曲（差动，驱动通道 CH2） |

## 3. SDK 逻辑关节与映射规则

### 3.1 四指控制映射规则 (`move_finger`)
在 SDK 2.0 接口中，四指的 `finger_index` 取值范围为 `1..=4`（从食指到小指）：
- `finger_index = 1`：**食指 (Index)** ➔ 起始关节 J12（范围 J12 ~ J15）
- `finger_index = 2`：**中指 (Middle)** ➔ 起始关节 J8（范围 J8 ~ J11）
- `finger_index = 3`：**无名指 (Ring)** ➔ 起始关节 J4（范围 J4 ~ J7）
- `finger_index = 4`：**小拇指 (Pinky)** ➔ 起始关节 J0（范围 J0 ~ J3）

计算公式：`start_joint_id = (4 - finger_index) * 4`。传入非法索引（如 0 或 >4）将由 SDK 校验并阻断报错。

每根四指传入的 4 个目标位置固定遵循：`[Abd, MCP, PIP, DIP]`。

### 3.2 大拇指控制映射规则 (`move_thumb`)
大拇指拥有 5 个独立自由度，调用 `move_thumb()` 时固定传入包含 5 个浮点目标的数组，公共逻辑顺序严格为：
1. `J16`: **CMC Rotation**（自转对掌，对应底层驱动通道 `CH4`）
2. `J17`: **MCP**（指根屈伸，对应底层驱动通道 `CH3`）
3. `J18`: **IP**（指尖屈伸，对应底层驱动通道 `CH0`）
4. `J19`: **CMC Abduction**（外展内收，对应底层驱动通道 `CH1`）
5. `J20`: **CMC Flexion**（腕掌屈伸，对应底层驱动通道 `CH2`）

底层硬件驱动通道映射关系：
```rust
match thumb_logical_joint {
    0 => 4, // J16 Rotation -> CH4
    1 => 3, // J17 MCP      -> CH3
    2 => 0, // J18 IP       -> CH0
    3 => 1, // J19 CMC Abd  -> CH1
    4 => 2, // J20 CMC Flex -> CH2
}
```

## 4. 物理电气接口与接插件定义

| 接口名称 | 接插件型号 | 信号与电气定义 |
| :--- | :--- | :--- |
| **RS485 通信** | `A1257WV-S-2P-6T` | 差分通信接口，推荐 5M 波特率，需使用双绞屏蔽线 |
| **CAN FD 通信** | `A1257WV-S-2P-6T` | CAN FD 高速通信接口 |
| **EtherCAT 通信** | `A1257WV-S-5P-6T` | 独立纯 C++ IgH 工业以太网通信接口 |
| **主电源 VCC** | `XT30UPB-M` | 直流电源输入：**24V ~ 80V 宽压**（推荐 24V / 额定功率 > 100W） |
| **触觉扩展 VBTS** | `A1257WV-S-10P` | 分布式触觉传感器阵列与数据传输扩展接口 |

## 5. 通信拓扑与默认设备 ID

- **默认从机 ID (Slave ID)**：
  - 默认左手 ID：`126`
  - 默认右手 ID：`127`
  - 广播控制 ID：`0`（向 ID 0 发送命令将同步控制总线上所有设备）
- **开机自校准安全须知**：
  - 灵巧手上电后将自动执行一次手指零位自校准，在此期间五指将全部张开；
  - **安全警告**：若上电时灵巧手正抓握物体，自校准会导致物体脱落，请务必在空载状态下上电启动。
